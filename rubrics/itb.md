## Lab requirements

The following requirements describe the necessary deliverables for the Virtual Private Cloud Design Lab.

| Criteria                                                                                                                                                                                       | Points |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| The submitted VPC diagram is a PDF file.                                                                                                                                                       | 5      |
| The submitted VPC diagram includes a CIDR block large enough to accommodate the current needs and future growth, but it's not so large that it wastes IP addresses.                            | 10     |
| The submitted VPC diagram uses appropriate IP addressing.                                                                                                                                      | 10     |
| The submitted VPC diagram uses separate and technically accurate subnets for each tier of the application.                                                                                     | 10     |
| The submitted VPC diagram uses public subnets for resources that need to be accessible from the internet and private subnets for resources that should only be accessible from within the VPC. | 10     |
| The submitted VPC diagram uses a consistent naming convention for subnets, making them easier to identify.                                                                                     | 10     |
| The submitted VPC diagram uses connectors to show the flow of traffic between components and subnets. At least 80% of these connectors are complete and accurate.                              | 10     |
| The submitted VPC diagram includes routing details. At least 80% of these details are complete and accurate.                                                                                   | 10     |
| The submitted VPC diagram includes security group details. At least 80% of these details are complete and accurate.                                                                            | 10     |
| A knowledgeable individual viewing the network diagram for the first time is able to understand the structure of the network.                                                                  | 20     |
| Visual elements and design in the network diagram are professional, and components are accurately represented.                                                                                 | 10     |
| **Total possible points**                                                                                                                                                                      | 100    |
